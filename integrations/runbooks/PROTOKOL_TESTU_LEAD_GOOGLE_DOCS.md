# Test obsługi leada

Ten sam test z każdą osobą. Ty siedzisz obok i podpowiadasz. Handlowiec klika u siebie.

Po wklejeniu do Google Docs: Narzędzia → Ustawienia → Wykrywaj Markdown automatycznie. Albo zaznacz listę i kliknij ikonę listy kontrolnej (kwadrat z ptaszkiem).

Na każdą osobę skopiuj cały blok „Sesja” poniżej.

---

## Sesja

Kto: _______________
Data: _______________
Testowy mail / telefon: _______________

### 1. Lead wpada

Wysyłamy testowy lead tak, jak zwykle wpada do tej osoby (formularz, Facebook, mail, albo przekazanie karty).

- [ ] Karta pojawiła się
- [ ] Jest u tej osoby, nie u kogoś innego
- [ ] Widać imię / firmę, telefon, mail i produkt

### 2. Handlowiec ogarnia kartę

Robi to sam, Ty tylko patrzysz.

- [ ] Znajduje kartę na swoim lejku
- [ ] Wpisuje w wyszukiwarkę telefon i trafia w tę samą kartę
- [ ] Dodaje krótką notatkę (np. „rozmowa testowa”)
- [ ] Odpisuje z własnej skrzynki (nie z firmowego owocni@)
- [ ] Wiadomość wyszła i widać ją przy karcie

### 3. Przesuwa etap, ale jeszcze nie kwalifikuje

- [ ] Przesuwa kartę do następnej kolumny (np. z Nowych do Rozeznania)
- [ ] Wie, że to jeszcze nie jest SQL

### 4. Kwalifikuje leada (SQL)

To świadomy przycisk / potwierdzenie, nie samo przeciągnięcie kafelka.

- [ ] Klika „Przyjmij jako SQL” albo potwierdza kwalifikację w okienku
- [ ] Karta jest na etapie kwalifikowanym

### 5. Oferta

- [ ] Przesuwa kartę dalej (oferta / analiza)
- [ ] Wie, że to jeszcze nie jest wygrana

### 6. Zamyka jako wygraną

Najpierw kwota, potem wygrana. Testowo wystarczy 1 zł.

- [ ] Wpisuje kwotę
- [ ] Zamyka jako wygrany
- [ ] Kwota została na karcie

### 7. Dwa inne zakończenia (na osobnych testowych kartach)

Żeby nie mylić trzech różnych „nie”.

- [ ] Odrzuć leada = takich nie chcemy z reklam (etap karty zostaje)
- [ ] Przegrany = klient nie kupił (to nie to samo co odrzucenie)

### 8. Na koniec sesji

- [ ] Osoba umie to powtórzyć bez Ciebie
- [ ] Co utknęło: _______________

Wynik: OK / do poprawki / nie da rady

---

## Ty sprawdzasz po sesji (handlowiec tego nie robi)

- [ ] Lead z formularza / reklamy w ogóle wszedł
- [ ] Kwalifikacja poszła dalej (nie tylko kafel na lejku)
- [ ] Wygrana poszła z kwotą
- [ ] Odrzucenie poszło jako odrzucenie, nie jako przegrana
- [ ] Przegrana nie poszła do reklam
